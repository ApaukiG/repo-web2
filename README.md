# Primera Oportunidad

Plataforma web (demo) para ayudar a jóvenes recién egresados en Ecuador a superar el desempleo y el subempleo: capacitaciones, mentores, bolsa de empleos/pasantías junior y panel de seguimiento.

## Stack

- Vite + React
- Tailwind CSS v4
- React Router
- Datos mock en el navegador (sin backend)

## Cómo instalar y ejecutar

```bash
npm install
npm run dev
```

Abre la URL que muestre Vite (por defecto `http://localhost:5173`).

### Otros comandos

```bash
npm run build    # build de producción
npm run preview  # previsualizar el build
```

## Páginas

| Ruta | Contenido |
|------|-----------|
| `/` | Inicio — hero, contadores INEC, pilares, testimonios |
| `/el-problema` | Tres causas validadas + citas |
| `/capacitaciones` | Catálogo filtrable, simulador de entrevistas, guía |
| `/mentores` | Red de mentores + perfil joven ejemplo |
| `/empleos` | Bolsa junior con filtros y seguimiento de postulaciones |
| `/mi-panel` | Dashboard del usuario joven |
| `/empresas` | Beneficios + formulario para publicar ofertas |
| `/nosotros` | Proyecto, metodología y equipo |
